### Example: spawn a coding‑focused sub‑agent with *minimax.1*

```json

  "label": "coding‑minimax"
```

### Things to keep in mind

- **Free‑tier limits:** Both `kilo` and `minimax.1` are free‑tier models, so they have rate limits and token caps. If you hit those limits, the system will automatically fall back to the default free model (`openrouter/openrouter/free`).
- **Persistence:** Using `mode: "session"` creates a lasting context that remembers previous messages, which is handy for longer coding projects. `mode: "run"` gives a fresh context each time.
- **Switching back:** If you later want the default model again, just spawn a new sub‑agent without a `model` override (or set the override to `"openrouter/openrouter/free"`).
